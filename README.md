# Bioinformatics MSc Coursework

Projects and coursework created during an MSc in Bioinformatics. The repository preserves the original implementations and their Git histories as a record of study work rather than actively maintained software.

## Projects

| Area | Project | Description |
| --- | --- | --- |
| Bioinformatics | [Biopython sequence analysis](bioinformatics/biopython-sequence-analysis) | Custom sequence analysis, database, visualization, and test modules originally developed inside a Biopython fork. |
| Bioinformatics | [PhyloAnalyser](bioinformatics/phylo-analyser) | Workflow combining sequence retrieval, clustering, alignment, tree inference, and comparison tools. |
| Bioinformatics | [Protein network comparison](bioinformatics/protein-network-comparison) | Script comparing neighboring proteins between STRING networks. |
| Data analysis | [Temperature analysis](data-analysis/temperature-analysis) | Data cleaning and visualization exercises using a temperature dataset. |
| Data visualization | [Interactive plots](data-visualization/interactive-plots) | Scripts and generated interactive visualizations. |
| Data visualization | [Spain COVID-19 project](data-visualization/spain-covid-project) | Final visualization project based on Spanish COVID-19 data. |
| NLP | [Polish Web Language Scorer](nlp/polish-web-language-scorer) | Experimental web-text difficulty scoring based on a Polish word-frequency dictionary. |
| Statistics | [SAD lab 04](statistics/sad-lab-04) | R exercises and notes from a statistics lab. |

Individual projects may depend on historical package versions or external tools. Their local documentation describes the original setup where available.
